# Repository map

- `apps/frontend`: React + TypeScript + Vite client.
- `apps/backend`: Node.js + TypeScript remote-browser service.
- `packages/protocol`: shared WebSocket schemas and types.
- `compose.yaml`: local development environment (added with Docker support).

Use pnpm only. Common checks are `pnpm typecheck`, `pnpm lint`, `pnpm test`, and `pnpm build`.
